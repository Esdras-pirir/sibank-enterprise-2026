# SIBank Enterprise 2026 🏦

**SIBank Enterprise 2026** es un sistema bancario completo desarrollado como proyecto de portafolio profesional, simulando la arquitectura de software de una institución financiera moderna. El sistema está estructurado en 4 capas independientes.

---

## 🚀 Arquitectura del Proyecto

1. **Base de Datos (Oracle):** Gestionada mediante PL/SQL, incluye 24 tablas, procedimientos almacenados, paquetes, triggers de auditoría y funciones de negocio.
2. **Backend (Java Spring Boot):** API REST robusta que maneja la lógica de negocio central, conexiones seguras y configuración CORS.
3. **Aplicación de Escritorio (C# Windows Forms):** Cliente pesado de escritorio diseñado en Visual Studio con componentes personalizados (`OnPaint`), utilizado para las operaciones diarias de los empleados del banco.
4. **Portal Web para Clientes (HTML, JS, React vía CDN):** Interfaz moderna de banca digital con estilos personalizados y modales dinámicos sin necesidad de herramientas de compilación complejas.

---

## 🛠️ Tecnologías Utilizadas

- **Base de Datos:** Oracle Database (SQL Developer)
- **Backend:** Java Spring Boot (NetBeans)
- **Escritorio:** C# / .NET Windows Forms (Visual Studio 2022)
- **Frontend Web:** HTML5, CSS3, JavaScript, React (vía CDN/Babel)
